# Directional Roadmap

This roadmap preserves future product directions only. It does not authorize implementation, change Joint's current MVP contract, or replace a purpose-specific implementation plan.

The implemented Bills & Groceries subset remains separate from the obligations direction: protected Bills/Groceries taxonomy, optional inclusive Bills service periods for analytics-only proration, and the protected Groceries category's one optional current recurring monthly budget as its threshold. Ledger and shared-balance accounting still use stored amounts and posting dates.

| Order | Feature                | Description                                                                                                                                                | Depends on                                                                               | Status                                                                                |
| ----- | ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 1     | Budgets & Goals        | One current recurring monthly budget on each active expense category or subcategory, with independent overlapping parent/child rows, plus manually maintained savings goals with target, saved amount, and needed-by date. | Live categories, transactions, dashboard reporting, and the combined Budgets & Goals contract. | In progress (contract approved) |
| 2     | Recurring Expenses     | Delivered: optional income and expense schedules automatically create idempotent weekly/monthly ledger transactions.                                       | Live categories, authenticated transaction actions, transaction ledger, and Vercel cron. | Implemented                                                                           |
| 3     | Bills and Analysis     | Future manually maintained obligations, upcoming and overdue states, and explainable expected-versus-recorded analysis after recurring-expense scheduling. | Recurring-expense scheduling; ledger, categories, and dashboard reporting.               | Directional                                                                           |
| 4     | Automatic Labelling    | Optional consent-gated category suggestions from transaction text with no model-authorized financial mutation.                                             | Live authenticated categories and manual transaction entry.                              | Directional                                                                           |
| —     | Transaction CSV Digest | Template-based read-only digest direction.                                                                                                                 | `docs/plans/transactions-statement-import.md`                                            | Superseded by `docs/plans/transactions-statement-import.md`; no implementation order. |
